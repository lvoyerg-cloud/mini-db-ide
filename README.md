# Mini DB IDE - Entorno de Desarrollo SQL y NoSQL

Entorno grafico desarrollado en Python para la gestion e interaccion con bases de datos relacionales (SQLite) y no relacionales (MongoDB).

## Caracteristicas
- Conexiones independientes a SQLite y MongoDB.
- Ejecucion de comandos DDL y DML.
- Visualizacion de resultados mediante tablas integradas.

## Ejecucion
```bash
pip install -r requirements.txt
python main.py
```
